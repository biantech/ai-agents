## 9. 分析原则

1. **先定性后定量：** 先理解商业模式，再看数字。
2. **纵向 + 横向对比：** 跟自己历史比 + 跟同行比。
3. **关注现金流胜过利润：** 利润可调节，现金流难造假。
4. **独立思考：** 研报观点仅供参考，需自行验证关键假设。
5. **动态跟踪：** 投资分析不是一次性的，需随季报/行业变化持续更新。
