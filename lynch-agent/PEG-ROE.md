
# 财经数据网站推荐（按分析用途分类）

> 📅 整理日期：2026-07-29
> 🎯 用途：彼得·林奇式基本面分析（PEG、ROE、毛利率、现金流、股息率等）

---

## 一、查原始财报（年报/季报PDF）

| 网站 | 网址 | 优势 | 适合场景 |
|:--|:--|:--|:--|
| **巨潮资讯网** ⭐首选 | cninfo.com.cn | 证监会指定披露平台，更新最快，不用注册，PDF直接下载 | 查原始季报/年报全文、分红公告、问询函 |
| 上交所/深交所官网 | sse.com.cn / szse.cn | 官方权威 | 查招股书、并购重组等深度文件 |

> 💡 分析中用到：Q1扣非增速、毛利率变动、现金流数据 → 全部来自季报PDF原文

---

## 二、查财务指标（PE/ROE/毛利率/现金流对比）⭐最核心

| 网站 | 网址 | 优势 | 免费？ |
|:--|:--|:--|:--|
| **东方财富网** ⭐首选 | eastmoney.com → 个股 → "财务分析" | 自动生成利润表/资产负债表趋势图，高亮异常值，50只股票可以逐个快速查 | ✅ 免费 |
| **同花顺iFinD** | 10jqka.com.cn → "财务" | 杜邦分析、行业对比、单季度拆分做得最好 | 基础免费 |
| **理杏仁** ⭐价值投资者最爱 | lixinger.com | PE/PB/ROE历史走势、估值百分位、股息率历史，做PEG分析最方便 | 基础免费，深度付费(¥300/年) |
| **看财报** | kancaibao.com | 专注基本面，股债比、股权收益率等价值指标 | ✅ 免费 |
| **知了财报** | zhiliaocaibao.com | 财报排雷、风险预警、行业对比（高毛利/高ROE/低估值分类） | ✅ 免费 |

> 💡 分析中用到：
> - PE(TTM)、股息率 → 东方财富 或 理杏仁
> - ROE、毛利率、负债率季度对比 → 同花顺
> - PEG计算需要的"G"（增速）→ 需要自己从季报算，或用理杏仁的"单季度增速"

## 三、查指数成份股

| 网站 | 网址 | 优势 |
|:--|:--|:--|
| **中证指数官网** ⭐ | csindex.com.cn | 输入指数代码（如H30097），直接下载成份股列表+权重 Excel |
| 东方财富 → 指数 → 成份股 | eastmoney.com | 可视化，带实时行情 |

> 💡 分析中用到：50只成份股的清单 → 来自中证指数官网

---

## 四、查研报/券商预期（前瞻增速G）

| 网站 | 网址 | 优势 | 免费？ |
|:--|:--|:--|:--|
| **东方财富 → 研报中心** | data.eastmoney.com/report | 券商盈利预测汇总（2026E/2027E净利润） | ✅ |
| **萝卜投研** | robo.datayes.com | 通联数据旗下，AI摘要研报 | 基础免费 |
| **慧博投研** | hibor.com.cn | 研报PDF下载最全 | 部分免费 |

> 💡 分析中用到：计算PEG时，"前瞻G"需要券商一致预期 → 东方财富研报中心最方便

---

## 五、批量筛选/编程取数（进阶）

| 工具 | 说明 | 适合 |
|:--|:--|:--|
| **AKShare**（Python库） | 100%免费开源，A股日线/财务/龙虎榜/北向资金，返回pandas DataFrame | 批量拉50只股票的财务数据做对比 |
| **Tushare** | 需注册获取token，免费额度够用 | 同上 |
| **同花顺i问财** | iwencai.com，自然语言选股："PE<30且ROE>15%且毛利率>30%" | 不会编程也能批量筛选 |

> 💡 分析中用到：如果要对50只成份股批量拉数据做PEG排名 → AKShare + Python 效率最高

## 六、我的推荐组合（针对林奇式分析）

```text
┌─────────────────────────────────────────────────┐
│  第1步：中证指数官网 → 下载成份股列表            │
│  第2步：巨潮资讯网 → 下载Q1季报PDF（原始数据）   │
│  第3步：东方财富/同花顺 → 查PE、ROE、毛利率      │
│  第4步：理杏仁 → 查PE历史百分位、股息率趋势      │
│  第5步：东方财富研报中心 → 查券商一致预期增速     │
│  第6步：自己算PEG → Excel或Python                │
│  （可选）AKShare批量拉数据 → 自动化排名          │
└─────────────────────────────────────────────────┘

## 七、一句话总结
| 需求 | 最佳选择 |
|:--|:--|
| 看原始财报 | 巨潮资讯网（免费、最快、最全） |
| 查财务指标对比 | 东方财富（免费）或 同花顺（单季拆分最好） |
| 做估值分析（PE/PEG/股息率） | 理杏仁（价值投资者神器，¥300/年值得） |
| 批量筛选 | i问财（不会编程）或 AKShare（会Python） |
| 查券商预期 | 东方财富研报中心 |
