# 分析数据的完整七步流程
## 第1步：确定股票池
来源：中证指数官网（csindex.com.cn）
操作：输入指数代码 H30097 → 下载成份股列表 + 权重 Excel
产出：50只成份股清单
## 第2步：获取原始财务数据
来源：巨潮资讯网（cninfo.com.cn）
操作：逐只搜索 → 下载最新季报/年报 PDF
提取：营收、归母净利、扣非净利、毛利率、经营现金流、负债率
产出：每只股票的原始财务数据表
## 第3步：获取估值指标
来源：东方财富（eastmoney.com）/ 同花顺（10jqka.com.cn）
操作：个股页面 → "财务分析" / "主要指标"
提取：PE(TTM)、PB、ROE、股息率、负债率
产出：估值指标对比表
## 第4步：获取历史估值百分位
来源：理杏仁（lixinger.com）
操作：输入股票代码 → 查看 PE/PB/ROE 历史走势图
提取：当前PE处于近5年/10年的百分位（如"30%分位"=偏便宜）
产出：估值贵贱的定性判断
## 第5步：获取前瞻增速（券商一致预期）
来源：东方财富研报中心（data.eastmoney.com/report）
操作：搜索股票 → "盈利预测" → 查看2026E/2027E净利润预测
提取：未来2年预期增速 G_forward
产出：前瞻PEG计算所需的G值
## 第6步：计算PEG并排名
工具：Excel 或 Python（pandas）
公式：
基础PEG = PE(TTM) / G(%)
调整后PEG = PE(TTM) / (G(%) + 股息率(%))
前瞻PEG = PE(TTM) / G_forward(%)
筛选条件：
PEG < 1 → 极具吸引力
PEG 1~1.5 → 合理
PEG > 2 → 偏贵
负增长 → 直接排除
产出：PEG排名表
## 第7步：林奇式综合评估 + 组合构建
叠加维度：
增速加速度（Q1 vs 年报，加速还是减速？）
毛利率趋势（上升=定价权增强）
现金流质量（利润有没有变成真金白银？）
负债率（>60%警惕）
林奇分类（缓慢增长/稳定增长/快速增长/周期/困境反转/隐蔽资产）
组合构建：
核心仓（35%）：PEG最低 + 基本面最强
进攻仓（25%）：高弹性 + 困境反转
价值仓（20%）：PE最低 + 安全边际
质量仓（15%）：品牌力 + 平台型
防守仓（5%）：低PE + 低负债 + 高股息
产出：最终Top 10 + 组合配置方案
